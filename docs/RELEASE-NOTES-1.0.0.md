# Codex TouchBar Monitor 1.0.0

Native macOS background monitor with the existing compact network/quota/launcher tray,
Desktop daemon task discovery, multi-execution dashboard, decision queue, command/file/permission
approvals, option pagination, free text and secure input, Chinese composition, foreground-aware
presentation, reconnection, notifications, login startup and private API fallback.

Includes desktop demo mode and offline protocol/UI checks; no physical Touch Bar is required for
those checks. All development and compilation take place in the build host workspace.

This artifact uses ad-hoc signing unless the optional Developer ID/notarization script has been run.
Physical Control Strip placement, third-party app coexistence and real IME candidate windows are
not claimed as hardware-verified. The built-in native text input path and simulated protocol flows
are verified separately. See REQUIREMENTS-1.0.0.md for requirement-level evidence and boundaries.
