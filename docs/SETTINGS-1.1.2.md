# 1.1.2 设置与应用图标修复

- 增加原生绘制的多分辨率 AppIcon.icns，打包写入 CFBundleIconFile。
- 设置分为 Touch Bar、系统通知、登录启动；说明通知等待时间及单位。
- 登录启动按钮仅刷新自身状态，不重建整个设置页；待系统允许状态单独显示。
- 增加标准应用菜单的“设置…”入口和 Command-comma 快捷键。
- 部署时不再传入覆盖 NotificationsEnabled / LaunchAtLogin 的测试参数。此前这类参数的 UserDefaults 优先级高于用户持久化设置，窗口重建后会让通知开关看似被登录启动改动。
- 本机真实设置验证：关闭通知时登录启动保持开启；恢复通知并关闭登录启动时通知保持开启；最后两项均恢复到原先开启状态。
- 安装包在远端构建并校验签名，本机仅运行。图标预览和中文设置页面已检查。

## 设置语言

- 设置顶部增加“语言 / Language”，可选中文和 English，即时生效并持久化。
- 标题、按钮、说明、错误和系统权限状态均支持两种语言；应用菜单和菜单栏的设置入口随之更新。
- 原位更新文字，不重建设置窗口，不丢弃未保存的数值，也不改变通知与登录启动。
- 本机已验证中文切换英文、重启后保留英文、再切回中文。
- 安装包包含图标；更新安装后重新注册应用并刷新 Dock，已核对启动台图标缓存为新版图标。
