# v1.1.2 — 独立额度账号、双语设置与应用图标

## 变更

- 设置新增“额度账号…”：可通过 OpenAI 官方登录页单独绑定或更换 Touch Bar 的周额度账号，Codex Desktop 登录和任务保持不变。
- 仅在新账号身份和周额度读取成功后切换；取消、关闭窗口、失败或不匹配的登录回调不会替换原账号。
- 支持恢复使用 Codex 当前账号；旧额度缓存与解除绑定后的独立凭据会清理。
- 独立账号使用本 App 专用目录和文件凭据存储；若系统策略强制共享凭据存储则拒绝绑定，不回退到其他账号。
- 设置可选择中文或 English，并记住选择；通知与登录启动分组且独立更新，通知等待时间含义和单位已明确。
- 打包多分辨率应用图标，修复更新安装时旧图标注册问题。

## 验证

- 指定构建机上全部 207 项自动断言通过：91 项核心、57 项协议/集成、23 项 UI、36 项独立账号测试；另含原生文本组件组合输入检查。
- 独立账号模拟测试涵盖登录成功、更换、取消、失败、重复点击、错误登录 ID、凭据策略冲突、持久化和恢复原来源。
- Release 构建、ZIP 内容及 ad-hoc 签名校验通过。
- 当前源码和发布包通过机器路径信息检查；不包含账号凭据、运行日志或本机数据库。
- 本机已通过官方登录页完成真实账号独立绑定，Touch Bar 显示实际额度；重启 Monitor 后额度仍正常显示。设置中文/English 切换及通知、登录启动互不干扰已验证。

## 范围与限制

- 本版本仅改变额度来源，任务/决策继续来自当前 Codex Desktop。
- 账号需具有可读取的 ChatGPT 周额度；浏览器可能保留已有登录，请选择并核对所需账号。
- arm64，macOS 13+，默认 ad-hoc 签名，尚未 Developer ID 签名或 Apple 公证。
- Touch Bar 私有接口及 Codex 内部协议可能随更新变化。
- Touch Bar 自由文本与中文 IME 仍暂停；远端任务、真实审批完整回路和长期休眠恢复尚未验收。

账号接口参考：[OpenAI App Server](https://developers.openai.com/zh-Hans/docs/app-server)、[凭据存储](https://developers.openai.com/zh-Hans/docs/auth)。
