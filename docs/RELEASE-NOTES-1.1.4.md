# Codex TouchBar Monitor 1.1.4

## 更新

- 支持发现并同时显示本机和已连接远端设备的 Codex 任务，远端标识前置，避免按钮截断后无法辨认。
- 按 host/thread/turn 隔离运行状态和待答复请求；回复明确路由到对应主机和 owner，避免跨设备串线。
- 修复 owner 重新连接、要求重报关注状态和 IPC 重置后的重新订阅；仅失效对应 owner 的状态，保留其他设备的任务。
- 后台每 30 秒补查新任务身份；运行状态仍来自实时事件，不将目录缓存冒充活动任务。
