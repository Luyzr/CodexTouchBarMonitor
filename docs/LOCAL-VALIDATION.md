# Milestone 1 本机 Touch Bar 验收

本机只运行 build host 构建的应用，不执行构建脚本。
测试包：CodexTouchBarMonitor-arm64.zip；解压后打开 CodexTouchBarMonitor.app。
当前测试包已在本机启动。菜单栏 CTB 可打开预览或退出。

## 实测步骤

1. 关闭预览窗口，切到 Safari、Finder、Ghostty、Zed、VS Code（以已安装应用为准）。
   核对原生应用按钮仍可用；记录组合item是否常驻、是否真正最右、是否被裁切。
   完整顺序必须为 网络时延 → 7D百分比 → Codex图标。
2. 分别测试 Control Strip 收起和展开，以及 Fn 状态。不要因预览完整就判通过。
3. Codex 已运行时点图标，确认只激活现有实例。
4. 在方便暂停当前工作的时机手动退出 Codex，再确认组合item仍在，点图标能启动并激活。
   当前Codex承载工作，不要为这一步强行中断尚未完成的任务。
5. 临时断开网络，等待最长约15秒，显示红色OFF；恢复后观察值恢复。
   HTTPS时延含代理/TLS/HTTP时间，不是纯网络ping；HTTP拒绝只证明连通，不能证明账号服务可用。
6. 额度读取失败时，无缓存显示7D--；有缓存继续显示但降低亮度。
7. 锁屏/解锁、睡眠/唤醒后检查显示。当前版本尚未专门处理ControlStrip服务重启。
8. CTB → Quit Monitor；确认自定义item消失，原生控件正常。

## 待填结果

- [ ] 最右侧、完整宽度
- [ ] 跨应用常驻且原生控件正常
- [ ] Codex已运行时激活
- [ ] Codex退出后仍显示，点击可启动
- [ ] 网络断开与恢复
- [ ] 额度缺失/缓存弱化
- [ ] 锁屏与唤醒
- [ ] 退出清理

任何未勾选项均未验证。自动化无法替代真实 Touch Bar 触控及物理布局检查。
