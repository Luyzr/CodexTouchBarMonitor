# 1.1.3 远端任务发现修复

- 从 Codex Desktop 跨主机目录只读获取 host_id 与 thread_id，不读取目录中的状态作为运行依据；排除 ChatGPT 聊天及缺失候选。
- 为本机和远端分别订阅 Desktop IPC 状态，按主机、任务、轮次隔离状态和决策。远端任务标题附加设备标识。
- 回复使用目标 owner、显式 hostId 与对应版本，防止同一任务 ID 在不同设备间串线。
- 启动、离开 Codex、手动刷新时发现任务；后台每 30 秒只补查目录中的新任务身份，执行状态仍由事件更新。
- Codex 未连接的设备不能凭目录缓存冒充实时运行；依赖 Desktop IPC 与目录结构兼容性。
- 自动测试共 218 项断言通过，包括跨主机同任务/请求 ID 隔离、远端完成、owner 更换、未订阅消息忽略和远端回复封装。
- 本机实际收到两台已连接远端设备的快照；另建只读短任务，收到执行中与完成事件。该验收未修改项目文件。
- 远端真实审批往返、设备单独断开重连和长期休眠恢复仍待专项验收。

## 1.1.4 连接恢复修正

- 处理 owner 请求重新报告关注状态、客户端重新连接和 IPC 重置；按原 host/thread 重新订阅，不依赖重启 Monitor。
- owner 断开时仅清除该 owner 的待决策和快照，未结束任务标为状态未知；保留其他 owner 的本机/远端任务。
- 尚未取得 owner 的目录候选在后续发现中重试订阅。
- 自动验证共 224 项断言通过（91 核心、36 独立额度账号、74 集成、23 UI），另含原生文本组合检查。离线 Unix socket 测试验证实际发送的重订阅消息、目标 owner、跨主机身份及重置广播。
- 本机安装包签名完整性验证通过；用户已确认当前本机任务重新出现。只读远端任务再次收到执行中事件。
- 用户已确认实体 Touch Bar 同时显示本机与远端测试任务；截图也显示两条运行中任务。远端按钮前置远端标识，避免设备后缀被截断。设备真实断开重连和休眠恢复仍需专项验收；离线重连测试不能替代这些硬件验证。
